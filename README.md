# E&P Signatur-Editor

Browserbasierter Editor für E-Mail-Signaturen in Gmail und Odoo.

Website: https://epsolutionsteam.github.io/signatur-editor/

## Verwendung
Name und Kontaktdaten eingeben, Darstellung wählen und Person speichern. Anschließend die Signatur kopieren und im Signaturfeld von Gmail oder Odoo einfügen. Eine Testnachricht zur Kontrolle senden.

## Daten
Keine vorbefüllten persönlichen Kontaktdaten. Personen werden ausschließlich im localStorage des jeweiligen Browsers gespeichert. Sicherungen können als JSON exportiert und importiert werden. Kein Backend, keine Analyse- oder Tracking-Skripte. Externe PNG-Symbole werden von Google, Flaticon und den jeweiligen Marken-Websites geladen. Firmenangaben und Logo sind öffentlich.

## Veröffentlichung
GitHub Pages: main, / (root). Die Website benötigt keinen Build-Schritt. Das Unternehmenslogo und die Liniensymbole werden von derselben Pages-Adresse geladen.
